# MEME AUTONOME — site public (lecture seule)
Recherche / simulation uniquement : argent fictif, aucun ordre réel, aucun conseil, aucun avantage démontré. Données publiques Bitvavo.
Cadence 2 h : remplissages et stops entre deux cycles reconstruits après coup à partir des transactions publiques.
`data/*.json` est écrit automatiquement par le cycle du dépôt privé (clé de déploiement). Avant le premier cycle, le site affiche « en attente du premier cycle GitHub ».
